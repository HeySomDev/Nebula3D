# Nebula3D

Nebula3D is a modular, open-source 3D web game engine framework for browser-based games built on TypeScript and Three.js.

## Highlights

- WebGL rendering and scene management
- Input system with keyboard and pointer support
- Component-based game object model
- Simple physics/logic hooks
- Procedural environment generation
- Playable arena game demo
- Open-source MIT architecture

## Quick start

```bash
npm install
npm run dev -- --host
```

Open the local URL shown by Vite in your browser.

## Demo controls

- Move: WASD
- Aim: mouse
- Fire: left click or space
- Objective: survive the enemy waves and keep the score rising
